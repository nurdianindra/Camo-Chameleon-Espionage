## 🚀 Getting Started

To begin your journey with the CamoHelper, you will need to acquire the latest stable build of the suite. We distribute the application as a **self-contained executable** that requires no external dependencies to run.

### Prerequisites

Before installation, ensure your system meets the following requirements:

- **Operating System**: Windows 10/11 (64-bit) or a recent Linux distribution (with Wine compatibility layer).
- **Hardware**: A dual-core processor or better, 4GB of RAM, and a graphics card that supports DirectX 11 or Vulkan.
- **Storage**: 50 MB of free space for the application and its configuration files.

### Installation Procedure

1.  Navigate to the download section below.
2.  Acquire the latest **CamoHelper Release Package**.
3.  Extract the archive to a dedicated folder of your choice (e.g., `C:\CamoTools`).
4.  Run the `CamoHelper.exe` executable. The application will run in the background and wait for the target game environment to initialize.

A formal, step-by-step **user manual** is included within the application's help panel, offering guidance on configuration and troubleshooting.

### 🎮 Initial Configuration

Upon first launch, the tool creates a default configuration file. This file is automatically backed up before any changes are made, ensuring you can always revert to a known-good state. We recommend reviewing the **"Sensitivity"** and **"Activation"** tabs within the UI to tailor the experience to your personal playstyle.

## ✅ FAQ & Troubleshooting

**Q: The tool does not seem to activate when I launch the game.**
**A:** Ensure you have run the application as **Administrator** and that your antivirus has not quarantined the executable. Add the installation folder to the exclusion list if necessary.

**Q: Can I use this on a laptop with an integrated GPU?**
**A:** Yes, the performance overhead is minimal. However, we recommend a dedicated GPU for the **Spectral Vision** module to run at high rendering distances.

**Q: How do I update to a new version?**
**A:** Simply download the new release and overwrite your existing executable. Your configuration file will be preserved and automatically migrated.
